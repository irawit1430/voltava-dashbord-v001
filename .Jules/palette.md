## 2024-08-24 - Accessibility standards for tabbed interfaces

**Learning:** When implementing tabbed interfaces in React components (like the DeviceDetailModal metrics chart tabs or GatewayConfig terminal tabs), it's crucial to establish clear `role="tablist"` for the container and `role="tab"` for each individual toggle button. Furthermore, ensuring that `aria-selected` is correctly mapped to the boolean active state of each button, and that it accurately specifies `aria-controls` for the associated `role="tabpanel"` improves screen reader comprehension substantially over relying on simple semantic `<button>` wrappers combined with CSS changes. In our custom design system, `aria-hidden="true"` should be applied consistently to Lucide-react icons in form controls (buttons, inputs) when there is accompanying text or descriptive `aria-label` attributes to prevent redundant announcements for screen reader users (e.g., standardizing `<X aria-hidden="true" />` for close buttons).

**Action:** Before submitting UI work with manual state-driven tab switching (such as data views or terminal shells), standardise the use of `tablist`/`tab`/`tabpanel` role groupings and explicit ARIA connections between the triggers and their corresponding content regions.
