🎨 Palette: [UX improvement] Add ARIA label to AI Assistant Send Button

💡 What: Added `aria-label="Send message"` to the icon-only send button inside the AI Assistant chat interface.
🎯 Why: Without an explicit ARIA label, screen readers will not announce the button's purpose since it lacks visible text (it only contains an icon), making the chat functionality inaccessible.
♿ Accessibility: Ensures the primary action for the chat component is keyboard and screen-reader navigable.
